title: 'Spinel: An Ahead-of-Time ''Ruby'' Compiler from Matz'
url: https://github.com/matz/spinel
category: Ruby Language & Internals
type: project
summary: Armed with AI, Matz has built a self-hosting compiler (for a subset of Ruby) that emits C which is then compiled to a native binary. It uses Prism for parsing and performs type inference. There are severe limitations (no eval or metaprogramming) and it can’t replace CRuby, but the performance potential is significant, though it's not a truly like-for-like comparison.
